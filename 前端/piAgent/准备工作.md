

# 安装

https://pideck.caoayu.top/guide/getting-started

可以直接安装 piDeck

```
git clone https://github.com/ayuayue/PiDeck.git
cd pi-desktop
npm install
npm run make-icon
npm run dev
```

事先准备好 node 和 npm

启动后如果本地未安装 pi agent，会自动检测进行安装，如果已经安装则可以检测到。


## 配置模型

可以在 *Pi 管理*  页面认证，添加 deepseek 认证，填入一个 apiKey 即可。这个与直接在 Pi 命令行使用 `/login` 是一样的。
